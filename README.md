# Programming Language Salary Analysis Using Web Scraping & Excel Visualization

This project demonstrates a complete data analysis workflow using **Python, Web Scraping, Data Cleaning, and Excel-based Visualization**.

The script scrapes a table of programming languages and their average salaries from a webpage, extracts and cleans the data, converts salary values into numeric format, sorts the results by highest salary, and generates an Excel report with an automated bar chart.

This project was completed as part of my **Data Analyst learning and portfolio development**, reflecting real-world analytical skills.

---

## 🎯 Project Objectives

- Scrape structured salary data from an HTML table using BeautifulSoup  
- Extract Programming Language names and Average Salary values  
- Clean salary fields (remove `$` and commas)  
- Convert salary values to numeric format  
- Sort programming languages by highest salary  
- Export cleaned data to Excel  
- Automatically generate a salary comparison bar chart

---

## 🛠️ Tools & Technologies

- Python  
- Requests  
- BeautifulSoup (bs4) — Web Scraping  
- Pandas — Data Cleaning & Transformation  
- OpenPyXL — Excel automation & charts  

---

## 📂 Workflow Summary

1. Download webpage HTML content  
2. Parse and locate the salary table  
3. Extract table rows into Python lists  
4. Convert data into a Pandas DataFrame  
5. Clean and preprocess salary values  
6. Convert salary column to numeric  
7. Sort data by highest salary  
8. Export results to Excel  
9. Add an automated bar chart inside Excel
